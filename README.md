# COVID-19-Data-Analysis

This project analyzes COVID-19 dataset using Python, Pandas, NumPy, and Matplotlib.

## Features

- Handles missing values
- Cleans COVID-19 dataset
- Calculates average, maximum, and minimum cases using NumPy
- Creates visualization charts

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib

## Files Included

- covid_dataset.csv
- covid_data_cleaning.py
- cleaned_covid_dataset.csv
- covid_visualization.py
- covid_graph.png
